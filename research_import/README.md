## 2. Core Architecture Summary

* **Data Ingestion:** Live 15m OHLCV candles from **Kraken** (unmanipulated volume, deep continuous history).
* **Order Execution:** Maker Limit orders on **BinanceUS** (0.0% maker fee tier, 1.9 bps taker stop loss).
* **Dual Passive Limit Spread:**
  - Maker Limit Buy at **-0.50% Discount** below signal close.
  - Maker Limit Sell at **+x* + 0.15% Premium** above entry (Fixed Limit Take-Profit).
  - Unfilled buy orders auto-cancelled after 1 bar (15 minutes).
* **Portfolio Sizing & Concurrency:**
  - Max concurrent open positions: **K = 5 slots**.
  - Position sizing fraction: **50% of compounded portfolio equity** per trade.
  - Sizing formula: `slot_capital = min(total_equity * 0.50, free_cash)`.
* **Active Universe Champions:**

## 3. How to Initialize in Accretion

### Step 1: Bootstrapping & Engine Initialization
```python
from crypto_live_engine import (
    CryptoLiveFeatureEngine,
    CryptoLiveInferenceEngine,
    CryptoDualLimitExecutionEngine,
    LivePredictionLogger
)

# 1. Initialize inference engine with exported models
inference_engine = CryptoLiveInferenceEngine(
    models_dir="models",
    discount_pct=0.50,
    sell_premium_pct=0.15
)

# 2. Initialize execution engine
execution_engine = CryptoDualLimitExecutionEngine(
    initial_capital=10_000.0,
    max_slots=5,
    position_size_fraction=0.50,
    discount_pct=0.50,
    sell_premium_pct=0.15
)

# 3. Initialize feature engine & warm-up with at least 672 bars of Kraken 15m history
feature_engine = CryptoLiveFeatureEngine(symbol="XBTUSD")
feature_engine.warmup(df_historical_kraken_15m)

# 4. Logger for live predictions
logger = LivePredictionLogger(log_dir="logs")
```

### Step 2: Processing Live 15-Minute Bars
```python
# When a 15m candle closes on Kraken:
features = feature_engine.on_new_bar(dt, open_p, high_p, low_p, close_p, volume)

if features is not None:

    if signal is not None:
```
